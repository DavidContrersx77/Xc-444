# XC!444 Tutorial

Sitio web educativo responsivo construido con HTML, CSS y JavaScript sin frameworks.

## Estructura
- `index.html`: contenido y estructura del tutorial.
- `css/styles.css`: diseño visual, tarjetas, navegación y adaptación móvil.
- `js/main.js`: menú móvil, indicador de lectura, resaltado del módulo y botones para copiar código.

## Cómo abrirlo en Visual Studio Code
1. Descarga y descomprime `XC!444_Tutorial.zip`.
2. Abre Visual Studio Code.
3. Selecciona **Archivo > Abrir carpeta** y elige `XC!444 Tutorial`.
4. Abre `index.html`.
5. Instala la extensión **Live Server** (si aún no la tienes).
6. Haz clic derecho sobre `index.html` y selecciona **Open with Live Server**.

También puedes abrir `index.html` directamente en el navegador, aunque Live Server facilita el trabajo mientras editas.

## Personalización
- Cambia textos en `index.html`.
- Ajusta colores y tamaños en `css/styles.css` (variables al inicio).
- Modifica interacciones en `js/main.js`.

## Recursos externos
Las fotografías se cargan desde Unsplash y los vínculos de consulta apuntan a documentación oficial. Se necesita conexión a internet para cargar fotografías, fuentes externas y abrir los recursos enlazados.

## Video
Se incluye un acceso al canal oficial de Android Developers y a búsquedas de tutoriales en YouTube. Así se evita depender de un video individual que pueda dejar de estar disponible o cambiar de dirección.
